# Fresh Market

A beginner-friendly static supermarket website made with HTML and CSS. Bootstrap CSS provides the basic layout and form styles.

## Pages

- `index.html` - Home page
- `products.html` - Product list
- `about.html` - About page
- `contact.html` - Contact form layout
- `dashboard.html` - Sample dashboard
- `login.html` - Login form layout
- `error.html` - Page not found

Every page links to the shared `css.css` stylesheet. Open `index.html` in a browser to view the site. The contact and login forms are visual examples and do not submit data or authenticate users.
